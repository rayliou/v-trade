# 目标与 ROI：先明确值得为多少增益付出多少成本

状态：研究提案，2026-09-13。用户已确认总投资本金为20万–40万美元、优先争取超过QQQ，最大回撤约30%作为研究上限，可能使用LEAPS；数据源总费用每年不超过1,000美元。实际分配给本策略的比例和账户税制尚未明确。以下成本和超额收益数字为情景或提案，不是预期收益。

## 把“年化高、持股体验好”变成选择标准

已知本金、USD计价和30%回撤研究上限后，还需落定策略实际分配金额、资金使用期限、可承受水下时间、能否持现金、杠杆/期权配置、账户税务类型、每周可投入时间。时区为Toronto并不能确定税务居民身份；在这些信息明确前，不给出个人税后收益结论。

**QQQ总收益是主收益基准**，体现用户的机会成本；美国宽基ETF只作辅助风格参照。另设“同样风险规则的QQQ+现金”对照，避免通过降低权益敞口获得较小回撤，就宣称选股产生alpha。风险匹配对照不能取代跑赢原始QQQ的主目标。

所有下列门槛是首轮拟议的最低实用改善，不是文献定律，也不等同于统计显著性。

| 目标路线 | 主验收标准 | 同时满足的护栏 |
|---|---|---|
| R：用户当前目标 | 样本外扣交易成本后，相对QQQ的CAGR差为正，并超过 `max(1个百分点, 年全成本/策略资金)`；固定费后仍应胜出 | 历史样本外最大回撤幅度≤30%，压力场景单独列示；持续检查Ulcer与水下时间。优选回撤不大于QQQ，原20%/15%改善提案仅作次要诊断 |
| H：可选降级用途，未被选作当前目标 | 样本外最大回撤幅度相对减少至少20%，且Ulcer Index相对下降至少15% | 扣交易成本CAGR落后QQQ不超过1个百分点；水下期不恶化；收益让渡和费用另经用户偏好接受 |

例：最大回撤由 -35% 变为 -28%，回撤幅度减少 7 个百分点、相对减少 20%。两种口径不能混用。

当前按R作为主路线，不可看完结果后用H“捞回”失败版本。若未来改选H，系统可能有使用价值但纯收益ROI为负；应记录用户愿意为风险减少或节省时间支付的预算，不能伪装成alpha。用户已选择最大回撤约30%、更重视跑赢QQQ；20%和25%只作为可选敏感性，不再作为待用户选定的主上限。30%是研究验收约束，不能保证未来不穿透，也不等同于触及该幅度才处理风险。

绝对收益 17–19% 仍是愿景，不设为首轮合格线。没有任何历史最大回撤或止损规则能够保证未来损失不超限。

## 净值体验与实际体验分别记录

| 维度 | 定义或观察方式 |
|---|---|
| 财富增长 | 时间加权总收益 CAGR；实盘另报资金加权收益 XIRR，外部出入金单独处理 |
| 回撤 | 每日净值相对历史高点跌幅；报告最大值、最差月/季和回撤路径 |
| 水下时间 | 跌破高点至恢复高点的交易日数；未恢复区间标记为尚未结束，不将其算成已恢复 |
| Ulcer Index | 全期每日百分比回撤的均方根；不采用只看个股近期最小回撤的替代指标 |
| 相对痛苦 | 相对主基准最长落后期、滚动 12/36 月超额收益，不能只看绝对净值 |
| 操作负担 | 每周维护分钟、有效/无效警报、月换仓次数、规则外干预次数 |
| 执行一致性 | 规则组合、人工复核后的组合和真实成交组合三条账本的偏差 |

研究表明投资者资金进出时点会让实际收益与基金总收益不同，但差额并不全是错误交易，也不能直接认领为系统可追回的收益。[Morningstar 2026 原文](https://www.morningstar.com/business/insights/research/mind-the-gap)。本项目必须用用户自身日志验证纪律与时间收益。

## ROI 的正确分母与成本

令：

- `A` = 真正受 VITALIS 管理的策略资金，而非家庭全部资产。
- `delta` = 相对替代方案的年收益差，已经扣交易、滑点、融资及同口径税影响，尚未扣系统固定成本。
- `C_cash` = 年数据、计算、存储等新增现金成本。
- `H0` = 一次性开发工时；`Hm` = 年维护工时；`v` = 每小时机会成本；`L` = 开发成本摊销年数。

```text
C_economic = C_cash + Hm * v + H0 * v / L
annual_incremental_value ≈ A * delta - C
break_even_delta ≈ C / A
project_ROI ≈ (A * delta - C) / C
```

这是稳定资金规模下的一年近似，不是多期现金流估值。CAGR 差也不是回归意义上的 alpha。交易与税若已扣进 `delta`，不得重复计入固定成本。没有税务输入时，回测及计算器只能标注税前口径；此时真实税后盈亏平衡可能更高。

## 可复算的基础情景

现金预算假设 `600 美元/年`：其中 Sharadar 完整历史 Bundle 年费官网为 499 美元，余下 101 美元仅为基础运行预算占位，不是报价；行情订阅、汇兑和税等若新增，另加。[供应商价格](https://sharadar.com/subscribe)。

总经济成本另假设开发 160 小时、年维护 20 小时、机会成本 50 美元/小时、摊销 3 年，因此每年约 `4,266.67 美元`。这些工时是规划估计；SEC 全自建清洗或更复杂产品可能超出，应按实际工时更新。

| 策略资金 USD | 现金口径保本收益差 | 全成本保本收益差 | 假设收益差 +2pp：现金净价值/年 | 假设收益差 +2pp：全成本净价值/年 |
|---:|---:|---:|---:|---:|
| 50,000 | 1.20% | 8.53% | 400 | -3,267 |
| 100,000 | 0.60% | 4.27% | 1,400 | -2,267 |
| **200,000** | **0.30%** | **2.13%** | **3,400** | **-267** |
| 250,000 | 0.24% | 1.71% | 4,400 | 733 |
| **400,000** | **0.15%** | **1.07%** | **7,400** | **3,733** |
| 500,000 | 0.12% | 0.85% | 9,400 | 5,733 |
| 1,000,000 | 0.06% | 0.43% | 19,400 | 15,733 |

**+2pp 只是敏感性输入，不是策略有能力产生 2% 超额收益的判断。** 基础情景下，若净收益差只有 1pp，全成本保本资金约为 42.67 万美元；2pp 时约为 21.33 万美元。若只有 20% 的总资产用于本策略，分母只能使用那 20%。

对用户20万–40万美元区间：若全部用于该策略，假设+2pp时现金口径每年净增3,400–7,400美元，全成本口径约-267至+3,733美元。若数据真用满1,000美元/年，仅数据费本身需要0.25–0.50pp收益差覆盖，其他费用和时间还要另加。**数据预算是硬支出上限，不是必须花完的目标。**

以 25 万美元、假设 +2pp 为例：全成本项目 ROI 约 17.2%，但首年若完整确认开发工时成本，成本是 9,600 美元，净价值仍为 -4,600 美元。使用摊销口径不能隐藏首次投入。

当 `delta=0`，纯收益净价值就是负固定成本；当 `delta=-2pp`，亏损再增加 `A×2%`。不能只报告成功情景。计算器默认同时给出 -2pp、0、+1pp、+2pp、+3pp。

## 可选功能的采购阈值

ORATS Delayed API当前标价199美元/月；若连续订阅12个月，仅订阅费约2,388美元，**已超用户数据预算，排除常年订阅**。对于20万–40万美元策略资金，这一项还需要约0.597–1.194pp年度净增益才能覆盖，未计接入维护。有限期试验只有在所有数据费合计≤1,000美元且有明确实验时才考虑。[ORATS](https://orats.com/data-api)。

短期研究采购与持续订阅应分别算账。不能假设订阅一个月后，下载数据就可以永久任意使用或用于商用；按实际合同核验。

若系统用途主要是节省研究时间，另算“已记录的净节省小时×用户时间价值”。不能一边将同一段维护时间记为成本，一边又把它当作节省收益；也不要将一个未经验证的“避免恐慌损失”加到 alpha 上。

## 经济决策

小资金账户更适合便宜的规则与研究辅助，复杂系统很容易被机会成本吞掉。较大策略资金有更好的固定成本摊薄，但不意味着信号更可靠。

先完成有限研究周期，再更新实际成本和净收益差证据。若纯收益不达标但风险与使用体验确有价值，可以缩减为个人风险和决策日志工具；此时明确采用体验预算，不宣称已证明赚钱能力。
