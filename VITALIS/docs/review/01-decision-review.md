# 决策复核：值得验证简化系统，暂不建设完整投资操作系统

日期：2026-09-13。范围：原稿全部 38 节、公开研究和供应商资料、本项目目录与当前 Python 环境。证据分为原文事实、外部证据、审查判断和待测假设。**本次没有运行投资策略回测，没有核实用户账户或数据订阅。**

## 三个问题的答案

| 问题 | 判断 | 成立条件 |
|---|---|---|
| 值不值得做？ | 值得投入一个封顶的研究周期；全面开发的经济性未证实 | 能用少量可靠数据与简单规则，相对便宜的可投资替代方案产生持续价值 |
| 应该这么做吗？ | 大方向合理，原来的先后顺序和部分建模方法应改 | PIT 数据先行；选股、仓位、风险提示分开；动态因子降权后置 |
| 支持够不够？ | 市面数据与普通电脑原则上足够做日频股票版；本仓库还没有可运行基础 | 补依赖、数据接入与验收、回测会计、可重复环境；确认个人数据授权 |

原稿的“17–19% CAGR、Sharpe 约 1、最大回撤约 20–28%”没有配套收益序列、样本范围、成本口径或实盘结果。它只能保留为愿景，不能成为估值、采购或实盘配置的收益预测。也不能从文献中存在动量与质量效应，直接推导这个系统能获得这些回报。

用户补充约束：总投资本金20万–40万美元，争取超过QQQ，回撤合理，可能使用LEAPS；数据总费用每年不超过1,000美元。这使初版股票研究在现金成本上可行，但“跑赢QQQ且更好持有”仍是较强的双目标，不能以只降低回撤替代收益目标。按02的假设，全部本金用于本策略时，600美元年度现金成本对应0.15–0.30pp的保本收益差，计开发维护时间约需1.07–2.13pp。若只分配部分本金，门槛更高。

## 原文值得保留的部分

1. 用总财富、回撤和可坚持性共同衡量结果，而不是只追逐 CAGR。
2. 排名和组合分开，设置仓位上限、行业及经济驱动重叠约束。
3. 股票池要有历史时点，财务信息必须按当时可得时间进入。
4. 用周度观察、月度复核和不同进出门槛减少小幅排名变动带来的交易。
5. 期权首先作压力传感器，LLM 作事实抽取与解释；这些定位比直接输出买卖判断更容易验证。
6. 以逐项增加功能的对照实验控制复杂度，先个人使用，再讨论外部产品。

质量和动量具备值得研究的历史依据，但相关研究通常覆盖更宽股票池，且常含多空组合。对“美国大型股、只做多、10–20 只、扣税与成本”的迁移仍须另测。[质量研究](https://www.aqr.com/Insights/Research/Working-Paper/Quality-Minus-Junk)、[动量研究](https://www.aqr.com/Insights/Research/Journal-Article/Momentum-Crashes)。

## 会改变建设决策的主要问题

| 原稿位置 | 问题及后果 | 修订建议 |
|---|---|---|
| §5、§19、§34 | 要求无幸存者偏差，却把正确股票池和 PIT 基本面放在 Phase 2；Phase 1 已包含 quality | 可靠历史股票池和必要 PIT 数据属于第一个有效回测的前置条件；免费样本只验管道 |
| §6、§12 | 动量、Sharpe、Sortino、Calmar、低回撤很可能重复奖励近期涨得稳的股票 | 初版只把动量与少量质量指标用于选股；持股体验主要在组合层检验 |
| §7、§10、§12 | 期权作压力传感器、宏观作风险条件，却又直接占总分 10%+10% | 从选股总分移出，先展示风险状态；要改变仓位须单独验证 |
| §20、§31、§35 | 最近 IC 变差不一定意味着信号失效；近期优先可能演变成追逐风格 | 固定模型作主线；活力监测先告警，只有成熟标签、足够样本与新样本验证后才改模型 |
| §15、§17 | 3–5 只股票与良好持股体验冲突，逆波动权重也未必改善整体经济风险 | 10 与 20 只为首轮候选，等权是必要基线；更集中版本后置 |
| §26 | 要先证明增量 alpha 才购买必需数据，逻辑上可能无法启动验证 | 区分“消除偏差的基础数据”和“追求增量收益的可选数据”；前者可设小额试验预算 |
| §32–33 | “Sharpe 提升 <0.10 就停止”与“任何一项改善即可成功”均太粗糙 | 预先选择收益或体验主目标，使用经济门槛、不确定性与风险护栏共同判定 |
| §18、§34 | 现金、总账户风险、税、持仓限制放得太晚；LEAPS被视为优势却未验证 | 账户约束进入 Phase 0；LEAPS 是独立风险策略，不由股票回测背书 |
| §6、§21、§24 | 指标很多，但缺少分母、缺失值、预测期限和成交时点定义 | 先冻结少量可计算、可复现的定义，再扩展指标 |

### 1. 高年化与舒适持仓存在真实取舍

减少波动和回撤往往需要降低权益敞口、限制热门行业集中度、持有现金，这可能错过快速反弹和牛市收益。单只股票历史上“涨得平稳”不代表未来抗跌；系统风险来临时，不同股票也可能一起下跌。

因此先画出几个简单方案的收益—风险比较，再选符合用户偏好的点，不把十余个指标优化成一个任意加权分数。需要分开评价“策略净值更平稳”和“用户更能坚持”，后者还受盯盘频率、提醒噪声、基准落后与人为干预影响。

收益贡献集中也不能机械否定策略。股票市场长期财富创造本来高度偏斜；该事实支持对集中持仓保持谨慎，并不证明任何选股模型必然失败。[Bessembinder 研究介绍](https://wpcarey.asu.edu/department-finance/faculty-research/do-stocks-outperform-treasury-bills)。应做移除最大贡献者、行业与时期分解，观察结果如何变化，而不是要求每只股票平均贡献利润。

### 2. “因子活力”是最容易过度承诺的部分

原文 IC 0.08→0.05→0.02→0.00 只是示例，缺少置信区间、样本数、标签期限和自相关信息。同一天 200 只股票不是 200 个独立市场环境；连续 252 天远期收益也高度重叠。

当下无法知道今天发出的 120 日预测是否有效，要等其标签成熟。若用尚未结束的未来窗口更新权重，回测存在前视偏差；若依据少数近期差值反复调参，则会制造第二层过拟合。多次试验本身会抬高最终胜出回测的表现，需要登记失败版本和修正统计证据。[Deflated Sharpe Ratio](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)。

保留活力仪表盘的研究价值，取消初版实时自动调权。先设置“数据故障、证据不足、表现正常、进入复核”四种状态，避免用 74/82 这样的整数制造未校准的精度。

### 3. 股票池太小可能把优势预先筛掉

100–200 只高流动性股票方便个人研究，却不是因子收益天然最强的范围。当前期权、周权和 LEAPS 条件可能进一步偏向现存大赢家，且给历史股票池增加难以回填的要求。

初版保留大盘、流动性与历史长度要求，取消期权资格作为股票策略硬过滤。未来使用期权时另建衍生品资格表。采用当时的规模规则，并报告整个历史期间的纳入/排除原因。

### 4. 市值指数的“进化”不是选股系统的免费优势

原文对指数自然增加赢家权重的描述适合作为比喻，不能证明主动替换更优。价格上涨导致市值权重提高，不需要投资者每次卖出再买入；主动换仓需要承担价差、税和卖掉随后继续上涨股票的风险。VITALIS 要证明的是在这些额外成本之后，仍比易执行的替代方案更好。

## 建议优先投入什么

| 能力 | 本轮优先级判断 | 为什么 |
|---|---|---|
| 数据时点、总收益、交易成本和退市处理 | 必做 | 决定结论是否可信 |
| 简单动量+质量、组合上限、月度纪律 | 先验证 | 有研究依据，复杂度可控 |
| 总账户风险、现金、决策日志 | 尽早加入 | 直接作用于持股体验和实际执行 |
| 手工维护少量经济驱动标签 | 小范围使用 | 当前风险解释有价值，历史回测须另有当时证据 |
| EPS 修正历史 | 后续候选 | 价值可能存在，真正的历史快照供给需核验 |
| 期权曲面、自动宏观调权、全量新闻和关系图 | 后置 | 显著增加费用、假设与数据处理面 |
| 商业化、多租户、自动实盘下单 | 暂不立项 | 个人价值、数据商用成本与运行可靠性未证实 |

这些是优先级判断，不是对各模块未来 alpha 的概率预测。完整工程能力不是眼下的稀缺资源；**能证明一个便宜、简单、可持有方案有增量价值的证据，才是第一阶段要购买和生产的东西。**
