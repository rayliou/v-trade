# 验证协议：先冻结测试，再判断是否值得继续

2026-09-13，拟议协议 v0.1；本轮未执行策略实验。主目标：扣成本收益超过 QQQ，同时有可接受的回撤与持股体验。具体资本、收益和风险口径以 [02](02-objectives-and-roi.md) 为准。

## 1. 必须先通过数据和会计门槛

以下任何问题未解决，不得发布“策略胜出”的结论：

- 使用今天存续股票代替当时股票池，或无退市/并购处理。
- 使用报表所属期作为可用日期，或将 MR 修订财务数据作为当时事实。
- 用收盘数据选股又假设同一收盘价成交。
- 未复权成交与复权收益混用，分红或拆股被漏算/重复算。
- 缺失报价当作零收益、停牌仍成交、退市资产无依据按最后价平仓。
- 用今天的主题/客户关系、行业或分析师共识回填历史。
- 非最终标签参与策略权重更新，或测试区间用于选择模型。

基准和策略必须使用相同交易日、币种、总收益口径。日记账包含现金、持股数量、交易费用、外部现金流和资产净值；各期“期初资产+投资损益+外部现金流=期末资产”可核对。TWR 排除外部入金影响，XIRR 用于真实账户结果。

## 2. 冻结少量候选，避免组合爆炸

| ID | 候选/对照 | 回答的问题 |
|---|---|---|
| B0 | QQQ 买入持有、股息再投 | 是否超过用户真正关心的机会成本？ |
| B1 | 宽基 ETF 总收益 | 结果是否只是科技/成长风格暴露？ |
| B2 | QQQ+现金，按与策略相同的风险覆盖方法 | 回撤改善是否主要来自降仓？ |
| C0 | 当期合格股票池全部等权、月度调整 | 200 只股票池本身有何影响？ |
| C1a/b | 动量，10/20 只，等权与相同集中度限制 | 动量选股是否有价值？ |
| C2a/b | 动量+质量，10/20 只，规则同 C1 | 增加质量是否改善收益和体验？ |

C2 对 C1 的比較使用相同股票池、时点和交易规则。数据覆盖差异不能当成质量贡献。先做上述比较；单独增加风险覆盖、逆波动或额外信号时，为每一变化新建实验 ID。初轮完整候选总数建议上限 12，包括试过后失败的参数；超过上限必须记录为何扩展，不能只保存胜者。

更多 Top-N、组合权重、阈值与回顾窗口不能一次全排列。首先测试一个经济假设，再做邻近参数稳健性。邻近参数检查也属于研究自由度，不能在最终封存集上边试边挑。

## 3. 时间设计

在供应商有效覆盖允许的条件下，建议：

1. 获取至少从 2000 年起的共同可用历史；更早数据有则用于补充。首个可交易时点还需 252 日价格与所需财务历史的预热，不能强行生成空窗信号。
2. 初始开发和错误修正以 2000–2014 的可用部分为主，涵盖多种市场路径。
3. 对 2015–2023 使用外层逐年 walk-forward。每年开始前只用以前的数据作决定；固定规则版不需要为了形式而每年训练，但所有候选选择只能在内层完成。
4. 2024–2025 作为一次性封存比较集；如果已有研究者反复看过这些策略结果，就只能称“历史检验区间”，不能称真正未见样本。宏观行情本身已众所周知，须承认研究者的背景知识。
5. 2026 年数据可以在数据完整到的时点作近期诊断，不能把未完成年度年化收益当完整年度表现。本轮审查日是周末，不自行声称行情已更新至某个交易日。
6. 最终版本冻结后开始至少 3–6 个月前向影子运行以检查操作，再考虑用户自行批准的有限实盘试验。这个长度主要证明运行一致性，不能证明长期 alpha。

若数据只有 5 年，不足以覆盖上述周期；改为管道与近期行为检验，结论应降级。不能把很多重叠 3 年窗口称为很多次独立验证。

## 4. 标签成熟与统计不确定性

IC 定义为同一日期股票信号与未来 h 日总收益的截面 Spearman 相关，h 固定为该实验登记的期限。月频主线先用 21/63/126 日作诊断，原文 1/5/20/60/120/252 日全期限扫描留待特定信号研究。

- 训练截止日之后才能结束的标签不得进入训练；用标签结束时间进行 purge。
- 若交叉验证设计会在验证区间之后使用训练样本，按最大标签重叠区间设置 embargo。普通严格前推分割不需要机械浪费一段数据，核心是确实无标签跨界和未来样本进入。
- IC 先按日期汇总，再用保留时间依赖的区块自助法/HAC 估计区间；不能把所有股票×所有日子摊平当独立观测。
- 比较策略和 QQQ 应使用同一时间块的配对重采样，保留它们之间的共同市场路径。区块长度根据标签与自相关预先设置并检验敏感性。
- 报告 CAGR 差、Sharpe 差和风险差的区间。单个置信区间不为复杂模型消除模型误设风险。
- 有多个尝试时，登记总数并采用 DSR 或适合设计的多重比较修正；明确其假设，不能将一个高 DSR 当未来收益保证。[方法来源](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)。

最近 IC 正负变化只是一个观测。至少报告已成熟截面期数、覆盖率、区间和是否集中于某行业；不存在一个普适的“IC 低于多少就死亡”阈值。若增加活力调权，整个“监控→决定→切换”过程必须作为新策略在外层样本测试，主线维持固定权重直到它获证。

## 5. 成交、成本与税的处理

股票首轮成本情景：对每次买/卖名义金额分别扣 5、10、25 bps 的综合执行成本，覆盖佣金/价差/滑点占位，避免与显式佣金重复记账。10 bps 是参照假设，不是已测用户成交成本；未来以实际券商费率与成交偏差校准。压力期提高成本并模拟延迟交易、成交缺失和跳空。

定义：每次再平衡的单边换手率 `0.5 * sum(abs(w_target - w_pretrade))`，包含现金且排除外部现金流。执行成本按实际股票买卖名义金额计算，不能直接用含现金的换手率乘费率而少算/多算。年内汇总单边换手，并单独报总买入与总卖出金额/NAV。

数据费/系统费不塞进个股 IC；组合报告另外给出 20万和40万美元资金下、扣固定费后的财富结果。股数离散、现金残余也应进入最终可执行回测。现金收益采用真正可获得的口径，避免在无利息账户中白算利息。

未明确账户税制时报告税前主线及显式“额外年度税拖累 0/0.5/1.0pp”敏感性，后者仅情景、不是税额预测。税会改变卖出时点和损益抵扣时，采用账户税批次重算，不能仅用平均税率替代。

## 6. 最低输出与归因

每个实验保存配置和数据版本、收益序列、持仓/交易序列、费用、遗漏与异常日志。摘要包含：

- CAGR、相对 QQQ CAGR 差、年化波动、Sharpe、Sortino、最大回撤、Ulcer、水下最长区间、最差月/季。
- 滚动 12/36/60 月相对收益及 Sharpe；现金比例、平均持股数、行业/主题集中度、换手、交易成本和固定成本。
- 证券/发行人/行业/时期的损益贡献，最大贡献者移除后的敏感性；实际账本不受此反事实修改。
- 对市场/成长科技/规模等可获得因子的暴露诊断，区分风格溢价、降低 beta、现金和残余收益。不能把任何相对 QQQ 的差额都叫独特 alpha。
- 符合信号期限的 IC 与有效样本区间；回撤与收益优势是否集中在一段行情。

Sharpe 使用每日超无风险收益均值/标准差乘 sqrt(252)，同时说明频率与年化假设；Sortino 的目标日收益与无风险/零收益选择在测试前固定。零下行偏差时返回未定义，不能显示无限优秀。Calmar 在无回撤或历史不足时也不强出数。

有负损益时，直接以“每只利润/总利润”计算 HHI 会失真。分别报告正贡献集中和负贡献集中；仓位 HHI 与利润集中分开。移除赢家的诊断不能被偷换成“赢股票多所以失败”。

## 7. 三态决策，而非任一指标漂亮就放行

| 结果 | 条件 | 决策 |
|---|---|---|
| 继续 | 数据与会计门槛通过，02 的收益与风险标准同时达到，成本压力和相邻参数下结论稳健，样本证据足够 | 进入影子运行；不直接全资金实盘 |
| 证据不足 | 点估计好但区间宽、样本短或过于依赖单段行情 | 不宣称胜出；冻结候选，优先增加真正前向证据，控制新增投入 |
| 停止/缩减 | 扣成本后不超过 QQQ且无已认可的体验价值；风险明显恶化；或依赖不可修复偏差 | 停止 alpha 扩展，保留有独立价值的数据、风险和日志功能 |

若收益目标没有达到，仅“比 QQQ 回撤低”不满足本次用户的完整目标；可以提出体验工具这一不同用途，但不得自动降低成功标准。表现坏也应先区分数据故障、正常风险暴露与策略失效，不能用短期亏损随机换参数。

所有结论要附“支持什么、不支持什么”：一份通过的历史报告支持有限试验，不能支持未来收益承诺、LEAPS 效果或商业化市场需求。
