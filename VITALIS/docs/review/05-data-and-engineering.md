### 硬预算账本（2026-09-13更新为真实订阅）

- **实际采购**：Sharadar Full History Bundle，**月付69美元**，2026-09-13首次生效（见`data/authorized/sharadar/subscription-status.json`）。这是真实支出，不再是情景数字。SEC/ALFRED数据访问收费按公开服务为0。
- 月付而非年付：若维持全年12个月不取消，年化支出为69×12=**828美元**，接近1,000美元总预算上限，剩余空间仅约172美元；这与此前"选年付499美元"的假设情景不同，499美元的年付选项**未被采用**。若中途取消，实际支出低于828美元，但不享有年付499美元的折扣。
- 每月都应重新核对该笔实际扣费是否为69美元、是否有税费或计费变动，不能一次记录后假设全年不变。
- 剩余预算（≤172美元/年，视实际是否满12个月而定）需覆盖新增券商行情权限、任何预测/期权试验、供应商税费与必要其他数据费；已存在但由本系统使用的数据订阅也应登记，不通过重复/遗漏口径规避总预算。
- 在此预算下，ORATS Delayed API（199美元/月）等历史期权数据**没有空间**再常年订阅，与02/05此前的排除判断一致，且比原499美元年付情景下的排除结论更明确。
- 基础股票研究不要求实时行情。月度策略不应为了"实时感"挤掉无偏历史数据预算。

## 2. 供应商存在，不等于数据已足够

### Sharadar 的三个关键细节

1. as-reported 与 most-recent 是不同维度；ARQ/ART 等适于研究当时报表，MRQ/MRT 包含后续重述。AR 也不保证每一个历史修订都完整保存，仍需抽样比对及延迟规则。[字段说明](https://sharadar.com/docs/fundamentals)。
2. 现在的直接 API 基本面日期字段叫 `date`，旧 Data Link 示例常见 `datekey`。适配器以实际 schema 建立映射，不照抄旧接口；发布日期、财务所属期和下载更新日期不能混为一谈。
3. `tickers` 文档明确为快照母表，含永久标识与存续信息，但当前行业、规模分类不因此变成历史快照。用公司行动、当时股数/价格及存档披露重构历史，或明确标记仍缺 PIT 的维度。[证券母表说明](https://sharadar.com/docs/tickers)。

进一步核查：当前FAQ列明历史SIC变更可由actions中的`sicchangefrom/sicchangeto`取得，永久`permaticker`用于代码变化；并购现金/换股有相应行动字段，但供应商估计对价覆盖约95%，不含或有价值权。最新交易所字段不是历史交易所记录。可作为接入候选依据，尚未取得全量并逐类验收；SIC到组合行业分组的映射也需版本化，不能直接把当前sector倒填。[官方FAQ](https://sharadar.com/docs/faqs)。

当前个人条款不覆盖公司、机构、商业或为他人服务的用途，也限制对数据衍生物的相关使用。初版个人研究与未来商业产品的数据路径应区别核算；不能假定付个人年费即可对外输出收费排名。[个人条款](https://sharadar.com/terms)。此处只是指出文档明确的范围，具体产品安排尚未进行法律判断。

### 免费数据能做什么

SEC Companyfacts 可用于核查原始事实，但跨公司科目、财年、单位、重复披露与重述仍需整理。`frames` 返回适合某日历期的最后申报事实，不能将其当作任意过去日期所见的全截面。公告原文还可能包含聚合 API 未覆盖的自定义/分部信息。

ALFRED 的 vintage 通常解决宏观修订问题，但对于同日交易仍须明确发布日期时分和可用延迟。普通当前新闻和当前关系不能重建十年前的决策背景。

Alpha Vantage 常规免费档为每日 25 次请求，200 只股票单端点完整刷新需要至少 8 天，因此不能默认支持全池日更；公开文档没有任意历史 as-of 参数，并不证明供应商绝无其他方案，只能说尚未核实满足需要。[免费额度](https://www.alphavantage.co/support/)。自己从今天开始存快照有前向价值，不能立刻生成历史修正序列。

ORATS near-EOD 样本采于收盘前约 14 分钟。把这些样本和官方收盘价格、OI 日期、财报公告时间混合时，要以实际时间对齐；合约、delta、年化与拟合方法都要版本化。股票预算紧时，历史期权绝不优先于历史股票池正确性。

## 3. 数据验收的最小清单

先用公开样本/合法试用验结构，再用已获权限的数据验覆盖。样本成功只证明样本，不代表全市场可用。

| 检查 | 必须保留的结果 | 不通过时的处理 |
|---|---|---|
| 历史覆盖 | 分年有效证券数、退市证券数、价格/基本面覆盖率，预热区间 | 缩小结论范围，不补今天赢家 |
| 企业行动 | 拆股、现金股息、并购、分拆、代码变化、退市各取真实事件重放 | 会计错误先修复；未知清算值作显式情景 |
| 财务时点 | 选约 20 个不同情况的 filing 对比原文与字段、报送时间、修订版本 | 纠正 available_at，不用所属季度代替 |
| 标识 | 发行人/证券/股类/合约 ID 对应，ticker 重用与变更记录 | 无稳定映射则隔离，不能粗略拼接 |
| 价格一致 | 未复权交易价、分红、复权系数与总收益桥接 | 禁止重复分红和拆股收益 |
| 约束/缺失 | 缺失原因、连续停牌、陈旧数据、行业标签日期 | 缺失值不补零、不使用未来字段 |
| 下载可靠性 | 分页、限流、重试、校验哈希、查询范围和返回行数 | 部分成功不能冒充完整数据 |
| 授权 | 账户实际可用表/历史、保存期限、个人使用范围和账单 | 记录未满足项后缩减模块 |

覆盖率应同时报分母：例如“当期应有行情的合格证券”，不能将已排除缺数据证券的集合当分母制造 100%。最终门槛建议为交易/持仓相关关键缺失未解释数为零；全市场非关键缺失保留清单并做敏感性。

## 5. 最小可实现架构

```text
供应商/披露源
    ↓ 不可变原始响应 + 时间/请求/哈希
标准化层（稳定 ID、公司行动、available_at）
    ↓ 数据质量门槛
历史股票池 → 因子快照 → 固定组合规则 → 交易/现金账本
                                          ↓
                              样本外评估 + 周度解释报告
```

确定主路径：不可变原始文件、Parquet+DuckDB研究数据、SQLite采集目录。先用标准库SQLite登记现有缓存并实现共享采集协调；授权样本验收后加入锁定版本的DuckDB/Parquet。当前不部署专门时序数据库服务，不同时引入多个DataFrame框架。项目独立环境和锁文件；不因为系统已装某包而依赖它，实际验证Python兼容性。

研究只能读取固定本地快照；远程补缺/更新属于显式采集任务，共享所有worker的限流、并发、请求去重与恢复检查点，不能在因子循环或UI刷新中请求供应商。现有CLI通过`--offline`达成重跑；统一调度、增量、目录及Parquet尚未实现。[本地数据设计](../prototype/local-data-architecture.md)、[用户接入步骤及实际限额](../prototype/data-source-onboarding.md)、[政策配置提案](../../config/data-source-policy.json)。官方未知配额标null，项目低速caps不是已确认权益。

原始响应只追加，规范表保留来源与修订。最少字段：`security_id, issuer_id, source, source_record_id, event_time, publication_time, available_at, ingested_at, valid_from/to, revision_id, value, unit, checksum`。历史批量采购的 `ingested_at` 是今天，不能因此否定全部历史；其历史 `available_at` 必须来自供应商 PIT 语义加明确延迟，而非凭空伪造。自采实时数据则保留真正到达时间。

研究必要表先做 `security_master / corporate_action / daily_price / universe_snapshot / fundamental_pit / factor_snapshot / portfolio_snapshot / trade_ledger / backtest_run / strategy_version / data_quality_issue`。原稿其他表待对应功能获证再加。

每个运行记录数据哈希、截止时间、代码版本、配置、实验 ID 和异常。定时任务需处理笔记本休眠、漏跑、时区和夏令时、券商重连、幂等与重放。数据不完整时冻结新的交易建议并显示最后成功时间；现有持仓的已知硬风险仍单独提示。个人只读工具先以文件导入持仓即可，不必为演示接通自动下单。

## 6. 是否足够的最终判断

**现有P001/P002工程样本已经可运行，正式历史研究所需数据及退出者结算仍未齐。** 最大缺口是历史覆盖、PIT/企业行动和统一采集，而非计算规模。1,000美元数据预算可支持严格限定范围的股票核心研究候选，不意味着订阅已验收。IBKR Gateway不是当前历史验证依赖；完整预测、期权、新闻与供需关系不列为必备。
