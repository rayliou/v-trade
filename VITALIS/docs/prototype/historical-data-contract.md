# 历史数据接入与P003验收清单

本清单用于个人研究。真实文件放在忽略版本控制的`data/authorized/`；不上传API密钥，不提交供应商原始数据。已有授权导出优先，没有订阅时先取得报价和样本，不自动采购。

## 接入范围

正式股票研究需覆盖计划研究期及至少252个交易日预热，包含当时进入和退出的证券。P001的2021–2025已被查看，仅用于诊断；在完整数据覆盖确认后另行冻结P003研究/选择/验证区间。不能根据免费源现存赢家补齐历史池。

CSV采用UTF-8、带表头；日期`YYYY-MM-DD`，时间用带时区ISO8601，价格与金额明确USD。空字段为缺失，不能填0。供应商原表可保留原字段，通过映射转换，不要求用户手工整理全部历史。

| 输入 | 最少字段/证据 | 失败条件 |
|---|---|---|
| `securities.csv` | 稳定`security_id`、`issuer_id`、证券类型、币种、上市区间；ticker映射及生效区间 | 代码重用或主/次股类混在一起 |
| `prices.csv` | `security_id,date,open_unadjusted,close_unadjusted,volume_unadjusted`；调整收盘与口径 | 持仓/交易日缺价未解释；复权价直接作成交价 |
| `actions.csv` | `security_id,event_id,action,effective_date,value`；公告/支付日、对手证券、结算依据 | 并购/分拆/退市不能重放，不能把最后价格自动当清算金额 |
| `fundamentals.csv` | 稳定映射、`dimension,filing_date,reportperiod`、质量所需数值和单位；原始记录标识 | MR伪装AR；所属期当可得日；不可说明历史修订语义 |
| `universe_evidence.csv` | 当时证券资格、行业、市场资本化及各字段可得时点 | 当前行业/规模字段倒填全部历史 |
| `benchmark.csv` | QQQ交易日、名义价、现金股息/拆股及调整价口径 | 股票和基准的再投、费用或日期口径不一致 |
| `provenance.json` | 来源、取得时间、文件哈希、范围、字段说明、个人使用权限和数据费用 | 部分返回被记为完整，费用累计超过1000美元/年 |

`valid_from`包含首日，`valid_to`排除该日；市场退出生效日、最后交易日和结算日分开保存。历史退出事件可以用于账本结算，不代表过去选股时预知退出。资格、财务和分类必须截至研究决策时已知。母表当前快照本身不满足历史行业/规模要求。

## 已完成的代码与尚未完成的部分

`vitalis/pit.py`可接收映射后的ARQ/ARY/ART财务字典，字段`date`明确为申报日；使用交易日历生成保守可得日，再用`fundamentals_asof`取截至日快照。只有日期时，推迟至申报后第一个交易日收盘；历史供应商实际到达语义需另外核查。数据采集/更新时间保留为溯源，不替代历史可得时间。

P002仅完成公开AAPL适配和检查，**不是全量CSV导入器，也没有历史股票池或退市结算实现**。拿到供应商实际样本后，先建立稳定ID映射、字段/分页/覆盖验收，再把合格数据连接到模拟器；这些工作完成前不生成正式质量组合结果。

## 每批验收与下一轮闭环

1. 冻结请求范围和配置；记录源文件及代码哈希、失败和重跑，保留原始响应。
2. 分年报告应有证券数、进入/退出者、缺价/缺财务数及分母；关键缺失必须有解释。
3. 真实拆股、分红、并购、分拆、代码变化、退市逐类重放；核对总收益、整数股、现金、费用和结算。
4. 抽查约20份披露的申报时间、所属期、AR数值与修订；截至日过滤不能看到未来。
5. 冻结P003：保持P001动量定义；先在历史池重建动量基线，再加质量对照。质量权重与样本区间在看结果前确定，不能把池变更与质量增量混作同一个效果。
6. 输出逐日账本、QQQ净CAGR差、约30%回撤门槛、水下期、Ulcer、换手、成本及贡献集中；记录继续/修改/停止/证据不足。

免费样本核验不会替代上述全量门槛。LEAPS、IBKR和自动下单仍后置。
