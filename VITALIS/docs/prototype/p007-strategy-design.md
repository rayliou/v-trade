# P007冻结记录：夏普动量 + 期权成交量/情绪候选

状态：**`frozen_unexecuted`**。2026-09-17的R010全项目复审取代此前“等待ORATS后继续”的路线图。不得据旧版本注册ORATS、购买数据、实现适配器或运行P007回测。

## 原假设

P006的普通成交量放量池叠加1个月原始收益排序，使H3归零、H5几近归零。P007原计划在相同放量池和质量过滤上，把排序改成21日日收益夏普，并使用期权成交量过滤候选、期权情绪诊断持仓风险，希望区分“健康放量”和投机放量。

这仍是一个未经验证的机制假设。期权活跃不天然代表更高未来收益或更低尾部风险；夏普排序也不能证明会修复P006的选择问题。

## 外部机制证据的适用边界（2026-09-19复核）

[Pan–Poteshman 2006](https://academic.oup.com/rfs/article-abstract/19/3/871/1646711)的强结果依赖“买方发起且开仓”的期权成交量，不能由普通 put/call 日总量重建。[ORATS near-EOD 字段](https://orats.com/near-eod-data)有期权成交量、未平仓量和 IV，但未列出该开仓方向标记；另售的[逐笔接口](https://orats.com/docs/time-and-sales-api)虽有推断的主动方，也不等于历史开仓买入字段。采购日快照不能自动复制论文结果。

[Johnson–So 2012](https://www.sciencedirect.com/science/article/pii/S0304405X12000797)的未标方向期权/股票成交量比中，高比值组历史收益较低，反驳“期权越活跃越健康”的单调直觉；[Ge–Lin–Pearson 2016](https://www.sciencedirect.com/science/article/pii/S0304405X16000167)又发现开仓买入 call 有信息，不能断言可用信息只在空头侧。[Cremers–Weinbaum 2010](https://doi.org/10.1017/S002210901000013X)发现的是 **IV 价差**在期权流动性高、股票流动性低的子样本预测力较强，不是对一切期权成交量过滤器的判决。

P007沿用P006的**全市场相对放量前100**候选和63日ADV不少于2,000万美元的资格门槛，计划持有3/5只；它并非P003–P005的市值前200、持有10/20只。流动性门槛可能削弱某些信息不对称机制，但现有论文没有检验这个具体池子、方向、月频和组合目标。以上证据增加机制与可得字段的疑问，**并未证明“即使数据免费，P007也必败”**；它与未过的数据、成本和预算门槛共同支持维持冻结。
