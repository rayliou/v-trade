# P007策略设计与路线图：夏普动量 + 期权成交量过滤 + 期权情绪诊断

这是一份**活文档**，在真正冻结预注册、拿真实数据出结果之前，可以随时讨论调整。跟`docs/review/08-decisions-and-coverage.md`的关系是：08是只增不改的正式决策台账（一旦某个口径经用户确认写进08，原则上不再在同一轮结果出来后修改）；这份文档是08背后的设计草稿和待办清单，供我们打磨细节、你追踪自己要做的事。08已有的2026-09-16预注册条目是本文档当前状态的正式快照，本文档内容更新后，如果涉及已冻结口径的实质变化，需要回填到08。

## 一、为什么走到这一步

- P001-P005：市值前200+12-1/6-1动量+10/20只分散持仓这条线，最终被P004/P005确认为"扣成本后跑不赢QQQ"，用户明确授权停止（详见08号2026-09-13条目、`p005-closeout-results.md`）。
- P006：换了完全不同的池子——全市场相对放量（5日/60日成交额比值）选热点，1个月动量，3/5只集中持仓。真实21年回测结果是**H3彻底亏光归零、H5几近归零**，两个变体相对QQQ的收益差90%自助法区间完全为负、不跨零——是统计上站得住的明确拒绝，不是"证据不足"（详见08号2026-09-14条目、`p006-hot-volume-results.md`）。
- P006自己给出的解读：普通成交量放量很可能系统性选中的是投机性、即将崩溃的标的，不是真正的"健康热点"。真正值得追问的是"能不能找到一个独立信号区分健康放量和投机放量"。
- 你提出的P007，正是这个方向：用**期权市场**的数据（成交量、情绪）作为独立过滤/诊断层，而不是继续在普通成交量这一个信号上调参数。

## 二、核心假设（一句话）

在全市场相对放量池里，**用夏普比（而非原始收益率）排序**能自然压低P006里那些暴涨暴跌的投机标的的排名；叠加**期权成交量门槛**作为候选资格（真正有期权市场关注度的标的，通常是更成熟、更不容易是"纯投机小盘股"的公司）；再用**期权情绪指标**作为持仓期间的风险诊断，帮助判断"这只票是不是已经没有其他候选有优势了，该被替换掉"。

## 四、已锁定 vs 还可以打磨的部分

**已锁定（写进08的2026-09-16预注册，不应该在看到结果之后为了让结果好看而改）：**
- 候选池、质量过滤方式、持仓数与调仓频率、主验收成本与回撤口径——全部延续P006。
- 排序改用夏普比，公式为`日均收益率/日收益率标准差`，零无风险利率，窗口不变（1个月/21交易日）。
- 期权情绪本轮先做诊断层，不做自动触发（除非你现在就要改，见下）。

**还可以打磨（现在讨论都不算"看结果后悔棋"，因为还没有任何真实结果）：**
1. **期权情绪指标具体用哪个？** 看跌看涨比（put/call ratio）、隐含波动率分位（IV percentile）、IV skew，还是几个一起看？各自能提前预警什么风险，需要你或者我们一起想清楚再定。
2. **期权成交量门槛怎么定？** 是"候选池内相对分位数前N%"（跟放量比一样走相对排名），还是"绝对合约张数门槛"？两种口径的候选池构成会很不一样。
3. **期权情绪要不要直接触发调仓？** 我目前的默认假设是"先做诊断，不触发"，避免一次实验里把"夏普+期权成交量过滤是否有效"和"期权情绪触发式风控是否有效"这两件事混在一起，看不出到底是谁在起作用。如果你希望这轮就要有触发机制，请明确说，我会把它做成独立可开关的配置，分开验证。
4. **H3/H5是否还是对的持仓数？** P006里H3直接亏光、H5也几乎亏光，拿到期权数据后可能需要重新评估3-5只是否还是合理的集中度，或者要不要先在更保守的持仓数（比如8-10只）上验证新信号有没有用，再收窄到3-5只。
5. **成本口径要不要考虑期权数据本身的固定成本？** ORATS一次性1,787美元/后续1,188美元一年，跟Sharadar的828美元一起，年度固定成本已经不小，是否要在回测里体现成一个更高的`annual_system_cash_cost_usd`，需要讨论。
