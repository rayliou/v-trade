# P008 协议：指数敞口与融资成本

状态：**`protocol_draft`**，未执行。授权来源：R011（2026-09-19 用户会话内明确授权，只推进机会地图前两条）。本协议只冻结规则与门槛，**不构成建仓建议**；作者不是持牌投资顾问。

## 1. 假设与机制

**机制是清楚的，而且必须先承认它不是 alpha：** 收益来自承担更多市场风险与支付融资成本之后的净风险溢价。它不需要证明本账户比机构更会选股。按 [AGENTS.md](../../AGENTS.md) R011 的要求，**杠杆/风险溢价必须与选股 alpha 分开记账**，不得合并成一个"跑赢 QQQ"的结论。

待检验命题：在扣除真实融资成本与产品费用后，适度提高指数敞口能否提升**全账户净复合年化（CAGR）**，且亏损路径可被实际承受。

## 2. 已完成的先验测算（本协议冻结前的诊断）

脚本 [`scripts/leverage_cost_diagnostic.py`](../../scripts/leverage_cost_diagnostic.py)：真实 QQQ 总收益代理日线路径 2005-01-03 至 2025-12-31（**含 2008**），日度再平衡恒定杠杆，融资按 FRED DGS3MO 真实短端利率加点，另计产品费率。只读，无新回测、无采购。

| 杠杆 | 加点 bps | 费率 bps | 净 CAGR | 最大回撤 | 相对 1.0x |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1.0 | 0 | 0 | 14.86% | −53.4% | — |
| 1.2 | 50 | 95 | 15.78% | −61.3% | +0.93pp |
| 1.5 | 50 | 95 | **18.45%** | **−70.8%** | +3.60pp |
| 2.0 | 50 | 95 | 21.87% | −82.5% | +7.02pp |
| 3.0 | 50 | 95 | 24.44% | −94.6% | +9.59pp |

三条结论，其中两条支持这个方向、一条是硬约束：

1. **在这条真实路径上，适度杠杆确实提升了净 CAGR，扣完融资和费用之后仍然提升。** 这一点应当直说：与 P003–P007 不同，这个方向的先验测算是正向的。
2. **存在明显的拐点。** 2.0x → 3.0x 只多买到 +2.57pp 的 CAGR，却把回撤从 −82.5% 推到 −94.6%。波动拖累使杠杆的边际收益递减而边际风险递增。**这在数据上支持"适度"（1.2–1.5x）而不是 2x/3x。**
3. **窗口效应极大，必须写进任何引用。** 同一套规则：2005–2014（含 2008）2.0x 只有 14.29% 对 1.0x 的 10.95%，**仅 +3.3pp**；2016–2026（不含任何系统性崩盘）2.0x 有 32.93% 对 20.53%，**+12.4pp**。机会地图引用的 QLD 十年 35.76% 属于后一类窗口。**该数字本身没错，但它主要反映窗口，不是产品优势。**

## 3. 本协议最关键的数据门槛

**当前路径起点是 2005-01-03，不含 2000–2002 纳斯达克下跌。** 这不是小事：NDX 在该期间的峰谷跌幅远超 2008，日度再平衡 2x 在那段路径上接近不可恢复。**任何关于杠杆敞口的结论，在补上 2000–2002 之前都不成立。**

好消息是这个缺口**免费可补**：QQQ 自 1999 年 3 月起有公开行情，本仓库已有 Yahoo 适配器 [`vitalis/data.py`](../../vitalis/data.py)。

> **数据门槛 G1（阻断性）**：取得覆盖 1999-03 至今的 QQQ/NDX 总收益日线序列，通过 [`vitalis/data.py`](../../vitalis/data.py) 的校验和缓存与复权口径检查，并重跑第 2 节全表。**在 G1 通过之前，本协议不得产出任何"适度杠杆可行"的结论。**

注意 [CLAUDE.md](../../CLAUDE.md) 记载的复权陷阱：`normalize()` 只能看到请求窗口内的拆分，窗口选择会影响名义价格重建；QQQ 有 2000 年的拆分历史，取数窗口必须一次性覆盖到今天。

## 4. 冻结的比较对象

| 工具 | 融资成本来源 | 可回测性 | 主要风险 |
| --- | --- | --- | --- |
| 普通 ETF（无杠杆基线） | 无 | 完全可回测 | 基线 |
| 杠杆 ETF（如 QLD） | 内嵌掉期融资 + 费率 | 可用第 2 节方法逼近 | 日度再平衡路径依赖；不等于多年两倍 |
| 券商融资 | 基准利率 + 券商加点 | 可回测，但需真实加点表 | **追保强平**；第 2 节模型未含强平，因此高估了高杠杆的存活率 |
| 深度实值 LEAPS | 隐含融资利率（利率、股息、波动率、滚动成本共同决定） | **不可回测** | 滚动成本与价差；无历史期权数据 |

**LEAPS 必须降级处理。** 本项目没有历史期权数据，ORATS 超出 1,000 美元/年上限且 R011 未授权采购。因此 LEAPS 只能做**定价模型层面的成本比较**（给定利率、股息、波动率推算隐含融资利率），**不得声称有回测结果**。

拟议研究范围 **1.2–1.5x**，这是研究区间，不是已验证的最优配置。

## 5. 验收与停止规则

**验收（全部须同时满足）：**

1. G1 通过，且包含 2000–2002 的全窗口下，候选配置的**全账户扣成本净 CAGR** 高于 QQQ 总收益代理。
2. 融资成本用真实历史利率序列，不用固定假设；券商方案须含追保强平建模。
3. 分窗口报告（至少 1999–2002、2003–2007、2008–2014、2015–2025），**不得只报全期**。
4. 同时报告最大回撤、水下时长、归零/强平概率。按 R011，这些不再是筛选门槛，但**必须披露**，因为它们决定复利能否走完。
5. 与选股 alpha 分开记账，不得合并表述。

**停止规则（任一触发即停）：**

- G1 无法取得合格数据 → 停止，登记数据失败。
- 含 2000–2002 的全窗口下，候选配置净 CAGR 不高于 QQQ → 停止，不再调杠杆倍数搜索。
- 任何候选在历史路径上触发强平/归零 → 该候选出局，不得通过降低倍数"捞回"后再宣称同一假设成立。

**投入上限：** 本协议只允许免费公开数据与现有代码；不采购、不接券商、不实盘。超出即须重新授权。
