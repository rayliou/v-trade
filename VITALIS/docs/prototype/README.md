## 一次闭环必须交付什么

| 步骤 | 必须留下的证据 | 结束条件 |
|---|---|---|
| 数据→ | 来源、实际访问结果、时间范围、时点语义、缺失与偏差 | 能区分管道样本与研究可用数据 |
| 规则→ | 冻结实验ID、参数、选股/仓位/执行时点 | 任一持仓能追溯到当时的数据和规则 |
| 账本→ | 日净值、现金、交易、费用、持仓与人工覆盖日志 | 总收益与公司行动正确，无同收盘前视交易 |
| 比较→ | 同期QQQ、必要的QQQ+现金对照 | 净CAGR差、回撤、水下期、Ulcer、换手及固定费有结果 |
| 决策→ | 继续/修改/停止/证据不足，并说明触发的标准 | 回写实验登记，限定下一轮只改变什么 |
| 再验证 | 新版本在未用于该次选择的数据上测试 | 不通过反复查看同一验证集美化结果 |

**工程闭环**可以用免费样本验证接入、计算、报告和错误处理；不能因为样本净值超过QQQ就宣称投资目标达成。**投资证据闭环**需04协议的历史数据、成本和样本外验证；之后通过前向影子记录检验运行与持有体验。免费当前股票池缺少历史退出者时，结论固定为“正式有效性证据不足”。
