# VITALIS 文档入口

本轮复核：2026-09-13。结论是**有条件值得做小规模验证，尚不值得按完整愿景全面开发，也没有证据确认收益目标能够实现**。

审查开始时，本目录只有一份初始需求稿，尚无策略实现、历史数据或回测结果。复核文档是设计审查与验证规范，不是策略业绩认证。用户已确认总投资本金 **20万–40万美元**、优先**超过QQQ**、最大回撤约**30%**作为研究上限、可能使用LEAPS，**数据源费用每年≤1,000美元**。IBKR留待后续接入；策略分配比例、账户税制和已有数据权益仍待补充。其他策略参数均为研究提案。

## 原稿与维护规则

[原始需求稿](<requirements/VITALIS — Dynamic Equity Selection & Strategy Vitality System.md>)完整保留，内容未改。它是愿景与历史背景；本轮 review 是修订提案，不能误认为已通过投资验证。发生冲突时，应先在 08 明确采纳哪个版本，再实施。

数字的权威位置：用户目标、ROI 假设在 02；策略参数在 03；实验与验收在 04；供应商和环境在 05；预算及阶段在 06。07 记录核查日期，不把网页价格视为永久事实。

[ROI 计算器](review/roi_scenarios.py)仅依赖 Python 标准库，输出情景 JSON；它不读取行情，也不估计未来收益：

```sh
python3 docs/review/roi_scenarios.py
```
